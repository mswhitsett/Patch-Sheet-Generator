IMPORTANT: The .github folder may be hidden on your Mac because it starts with a dot.

To upload this project to GitHub correctly:
1. Unzip this file.
2. Open the unzipped folder in Finder.
3. Press Command + Shift + . to show hidden files.
4. Confirm you can see the .github folder.
5. In GitHub, delete the old uploaded files/folder if needed.
6. Click Add file > Upload files.
7. Drag EVERYTHING inside this folder into GitHub, including .github, src, src-tauri, package.json, index.html, vite.config.js, and README.md.
8. Commit changes.
9. Go to the Actions tab and run "Build Mac App".
